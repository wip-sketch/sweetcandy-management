# Finance Care 🌸

Aplikasi manajemen keuangan personal untuk rumah tangga dan bisnis kecil menengah.

## Fitur

### 🏠 Rumah Tangga
- Pencatatan pengeluaran mingguan
- Pelacakan saldo per minggu
- Perhitungan otomatis sisa saldo
- Pembawa saldo dari bulan sebelumnya

### 💼 Bisnis
- Manajemen produk bisnis
- Pencatatan pembelian modal (bahan/alat)
- Pencatatan penjualan
- Perhitungan keuntungan bersih otomatis
- Kelola multiple produk

### 📂 Arsip Data
- Simpan laporan rumah tangga per bulan
- Simpan laporan bisnis dengan timestamp
- Lihat kembali laporan yang sudah disimpan

## Cara Menggunakan

1. **Buka Website**: Kunjungi https://wip-sketch.github.io/sweetcandy-management/

2. **Rumah Tangga**:
   - Pilih bulan/tahun
   - Masukkan total pemasukan
   - Tambahkan pengeluaran per minggu
   - Aplikasi akan menghitung saldo otomatis
   - Klik "Simpan Laporan" untuk arsip

3. **Bisnis**:
   - Tambah produk baru
   - Masukkan modal awal
   - Catat pembelian modal (bahan/alat)
   - Catat penjualan dengan tanggal
   - Lihat keuntungan bersih otomatis
   - Klik "Simpan Semua Bisnis" untuk arsip

4. **Arsip Data**:
   - Lihat semua laporan yang pernah disimpan
   - Klik untuk membuka kembali laporan

## Teknologi

- **HTML5** - Struktur
- **CSS3** - Styling dengan animasi bubble
- **Vanilla JavaScript** - Logika aplikasi
- **LocalStorage** - Penyimpanan data lokal

## Data Privacy

Semua data disimpan di **Local Storage browser Anda**. Data tidak dikirim ke server manapun dan hanya ada di perangkat Anda.
